Can we upload asset / job / defect + photo?
Live Public API vs Apidog vs MCP. Job photos are proven. Asset photos and defects are not. Includes the exact REST recipe and the ask for Vadim.
Capability note Job + photo ✓ Asset create ✓ · photo ✗ Defect ✗ Probed Jul 2026
01 · Verdict
Capability matrix
Apidog (rezzxstrv0.apidog.io) is incomplete — Jobs are list-only in the TOC; Files / Assets / Defects are undocumented. Live API and MCP diverge from the docs.
EntityCreateAttach photoNotes
Job Yes Yes — proven REST POST /jobs/ or MCP create_job. Photo via file flow below.
Asset Yes Not yet POST /assets/ needs site. Custom Photo image_list field exists; writing file IDs left value: null.
Defect No No /defects/ → 404. Not in Apidog. Not in MCP.
MCP (~69 tools at /mcp/) has job create/patch and asset catalog tools only — no photo/file tools, no asset instance create, no defects.
02 · Proven recipe
Job photo upload (undocumented, live)
1. POST /public-api/files/
     Content-Type: application/x-www-form-urlencoded
     body: name=leak.png&size=12345
     → { file_id, upload_url }

2. PUT {upload_url}
     Content-Type: application/octet-stream
     body: <raw bytes>
     → 200

3. POST /public-api/jobs/{id}/attachments/
     Content-Type: application/x-www-form-urlencoded
     body: file={file_id}
     → 200
Helper shipped. lib/fi-files.js + CLI:
FIELDINSIGHT_API_KEY=… node scripts/fi-upload-job-photo.mjs <jobId> ./photo.png
03 · Ask Vadim
Close the gaps
  1. Document + MCP-wrap POST /files/ and POST /jobs/{id}/attachments/ so agents can attach job photos without raw REST.
  2. Asset photos — official way to set image_list custom fields (or an attach endpoint) after /files/ upload. PATCH with file IDs currently no-ops.
  3. Defects API — create / list / attach photos. Missing entirely from Public API + MCP.
  4. Refresh Apidog so it matches live (job create/patch, assets, files, timesheets, quotes, POs…).
Copy-paste ask lives in Obsidian: Specs/fieldinsight-api-photo-upload.md § Ask Vadim. Also fi-22-vadim-photo-ask.md in this repo.
